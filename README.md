# Portfolio

Um portfólio moderno e interativo construído com tecnologias web de ponta, apresentando projetos e habilidades em full-stack development.

## 🚀 Tecnologias

**Frontend:**
- [Next.js 16](https://nextjs.org) - Framework React com SSR/SSG
- [React 19](https://react.dev) - Biblioteca UI
- [TypeScript](https://www.typescriptlang.org) - Type-safe JavaScript
- [Tailwind CSS 4](https://tailwindcss.com) - Utilitários CSS
- [Radix UI](https://www.radix-ui.com) - Componentes acessíveis
- [Three.js](https://threejs.org) & [Spline](https://spline.design) - Gráficos 3D interativos
- [Motion](https://motion.framer.com) & [tsParticles](https://tsparticles.js.org) - Animações fluidas

**Backend:**
- [MongoDB](https://www.mongodb.com) + [Mongoose](https://mongoosejs.com) - Banco de dados
- [JWT](https://jwt.io) & [bcryptjs](https://github.com/dcodeIO/bcrypt.js) - Autenticação segura
- [SendGrid](https://sendgrid.com) - Serviço de email

**Ferramentas:**
- [ESLint](https://eslint.org) - Linting
- [tsx](https://tsx.is) - Execução TypeScript

## 📁 Estrutura do Projeto

```
app/
├── page.tsx           # Landing page principal
├── projetos/          # Página de projetos
├── contato/           # Formulário de contato
└── api/               # Rotas API (autenticação, emails, etc)
```

## ✨ Destaques

- **Design Responsivo**: Funciona perfeitamente em mobile, tablet e desktop
- **Animações Dinâmicas**: Efeitos de partículas e transições suaves
- **Gráficos 3D**: Visuais interativos com Three.js e Spline
- **Autenticação**: Sistema seguro com JWT e criptografia
- **Performance**: Otimizado com Next.js e lazy loading
